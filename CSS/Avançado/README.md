
# CSS Avançado

## Objetivo

Nesta etapa vamos aprender técnicas avançadas de CSS usadas em projetos profissionais, com foco em organização, performance, manutenção e criação de interfaces modernas.

---

# Conteúdos

## 01 - Arquitetura CSS

Aprender:

- Organização profissional de arquivos CSS.
- Separação de estilos.
- Componentes.
- Código escalável.

---

## 02 - Metodologias CSS

Aprender:

- BEM (Block Element Modifier).
- Padrões de nomenclatura.
- Manutenção de projetos grandes.

---

## 03 - CSS Avançado com Layouts

Aprender:

- Flexbox avançado.
- Grid avançado.
- Layouts complexos.
- Sistemas de colunas.

---

## 04 - Animações e Transições Avançadas

Aprender:

- Keyframes complexos.
- Controle de animações.
- Performance de animações.

---

## 05 - CSS Variables e Temas

Aprender:

- Variáveis globais.
- Dark mode.
- Sistemas de temas.

---

## 06 - Pré-processadores CSS

Aprender:

- Introdução ao Sass.
- Nesting.
- Mixins.
- Organização com Sass.

---

## 07 - CSS Moderno

Aprender:

- Container Queries.
- CSS Functions.
- Clamp().
- Min().
- Max().

---

## 08 - Performance CSS

Aprender:

- Redução de código.
- Organização.
- Carregamento eficiente.
- Boas práticas.

---

## 09 - CSS para Frameworks

Preparação para:

- Tailwind CSS.
- CSS Modules.
- Styled Components.

---

## 10 - Projetos Profissionais

Aplicar CSS em:

- Landing pages.
- Dashboards.
- Sistemas web.
- Aplicações completas.
