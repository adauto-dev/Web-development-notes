
# CSS Profissional — Do Básico ao Avançado

## Objetivo

Dominar CSS para criar interfaces modernas, responsivas, acessíveis e organizadas.

O estudo será dividido em:

1. Fundamentos
2. Layout
3. Flexbox
4. Grid
5. Responsividade
6. Tipografia e efeitos visuais
7. Formulários
8. Animações
9. CSS moderno
10. Organização profissional
11. Acessibilidade e performance
12. Prática e projetos

> Este arquivo é o **mapa de estudos**.
> Não é necessário estudar tudo de uma vez. Os assuntos serão estudados progressivamente com teoria, exemplos, desenhos e exercícios.

# Critério para avançar

Não avançar simplesmente porque a teoria terminou.

Antes de considerar um assunto aprendido, conseguir:

* explicar o conceito;
* escrever o código sem copiar;
* entender o resultado;
* saber quando usar;
* saber quando não usar;
* resolver um exercício;
* corrigir erros comuns.

---

# Objetivo Final

Ser capaz de olhar para uma interface e decidir:

* qual unidade usar;
* quando usar px, rem, em ou %;
* quando usar vw, vh ou dvh;
* quando usar clamp();
* quando usar Flexbox;
* quando usar Grid;
* quando usar Position;
* como organizar o layout;
* como tornar a interface responsiva;
* como criar componentes reutilizáveis;
* como criar interfaces acessíveis;
* como investigar problemas no DevTools;
* como escrever CSS limpo e escalável.

Começar pelo:

`px → rem → em → % → vw → vh → dvh → fr → min() → max() → clamp()`
