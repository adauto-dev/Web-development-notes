
# CSS

## O que é CSS?

CSS significa:

**Cascading Style Sheets**

(Folhas de Estilo em Cascata)

CSS é a linguagem usada para definir a aparência e o design de páginas web.

Enquanto:

HTML → cria a estrutura.

CSS → cria o visual.

JavaScript → cria a interação.

---

# O que podemos fazer com CSS?

Com CSS podemos controlar:

- Cores.
- Fontes.
- Tamanhos.
- Espaçamentos.
- Layout.
- Animações.
- Responsividade.
- Design para celulares e computadores.

---

# Exemplo simples

HTML:

```html
<h1>
Minha página
</h1>
```

CSS:

```css
h1 {

color: blue;

font-size: 40px;

}
```

Resultado:

O título fica azul e maior.

---

# Como CSS funciona?

CSS seleciona elementos HTML e aplica estilos.

Estrutura:

```css
seletor {

propriedade: valor;

}
```

Exemplo:

```css
p {

color: black;

}
```

Onde:

```
p
→ elemento selecionado

color
→ propriedade

black
→ valor
```

---

# Formas de adicionar CSS

## 1. CSS externo (recomendado)

Arquivo:

```
style.css
```

HTML:

```html
<link
rel="stylesheet"
href="style.css">
```

É o método usado em projetos profissionais.

---

## 2. CSS interno

Dentro do HTML:

```html
<style>

h1 {

color:red;

}

</style>
```

Usado em casos pequenos.

---

## 3. CSS inline

Dentro do elemento:

```html
<h1 style="color:red">

Título

</h1>
```

Normalmente evitado em projetos profissionais.

---

# Conceitos importantes de CSS

## Seletores

Escolhem quais elementos serão estilizados.

Exemplo:

```css
h1 {

color:red;

}
```

---

## Propriedades

Definem o que será alterado.

Exemplo:

```css
color
font-size
margin
padding
```

---

## Valores

Definem o resultado.

Exemplo:

```css
color: red;
```
