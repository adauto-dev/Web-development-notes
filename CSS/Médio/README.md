
# CSS Médio

## Objetivo

Nesta etapa vamos aprofundar o conhecimento de CSS para criar layouts mais profissionais, organizados e preparados para projetos reais.

---

# Conteúdos

## 01 - Box Model Avançado

Aprender:

- Controle de dimensões.
- Padding e margin profissionais.
- Box-sizing.
- Organização de espaçamentos.

---

## 02 - Flexbox Avançado

Aprender:

- Containers e itens.
- Alinhamentos complexos.
- Flex-grow.
- Flex-shrink.
- Flex-basis.
- Layouts profissionais.

---

## 03 - CSS Grid

Aprender:

- Grid containers.
- Grid columns.
- Grid rows.
- Áreas do grid.
- Layouts de páginas.

---

## 04 - Responsividade

Aprender:

- Mobile First.
- Media Queries.
- Breakpoints.
- Adaptação para dispositivos.

---

## 05 - Animações CSS

Aprender:

- Transitions.
- Transform.
- Animations.
- Keyframes.

---

## 06 - Pseudo Classes e Elementos

Aprender:

- :hover
- :focus
- :active
- ::before
- ::after

---

## 07 - Variáveis CSS

Aprender:

- Custom properties.
- Organização de temas.
- Reutilização de valores.

---

## 08 - Organização CSS

Aprender:

- Estrutura de arquivos.
- Nomenclatura.
- Boas práticas.
- Código limpo.

---

## 09 - CSS para Projetos Reais

Aprender:

- Cards.
- Menus.
- Landing pages.
- Componentes reutilizáveis.

---

## 10 - Preparação para JavaScript

Aprender:

- Manipulação de estilos.
- Classes CSS.
- Integração com páginas interativas.
