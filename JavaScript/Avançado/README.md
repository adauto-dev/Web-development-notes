
# JavaScript Avançado

## Objetivo

Nesta etapa vamos aprender conceitos avançados de JavaScript usados em aplicações profissionais, preparando para frameworks como React e desenvolvimento Full Stack.

---

# Conteúdos

## 01 - JavaScript Profundo

Aprender:

- Execution Context.
- Call Stack.
- Hoisting.
- Scope.
- Closures avançadas.

---

## 02 - Programação Orientada a Objetos Avançada

Aprender:

- Classes avançadas.
- Herança.
- Encapsulamento.
- Polimorfismo.
- Design patterns básicos.

---

## 03 - JavaScript Assíncrono Avançado

Aprender:

- Event Loop.
- Microtasks e Macrotasks.
- Promise chaining.
- Tratamento avançado de erros.

---

## 04 - APIs e Comunicação

Aprender:

- REST APIs.
- HTTP avançado.
- Headers.
- Autenticação.
- Tokens.

---

## 05 - Node.js

Aprender:

- Ambiente Node.
- Módulos.
- npm avançado.
- Criar servidores básicos.

---

## 06 - Banco de Dados

Introdução:

- SQL.
- NoSQL.
- Conexão com aplicações.

---

## 07 - Arquitetura de Código

Aprender:

- Organização profissional.
- Separação de responsabilidades.
- Clean Code.
- Boas práticas.

---

## 08 - Testes

Aprender:

- Testes unitários.
- Testes de integração.
- Introdução ao Jest.

---

## 09 - Performance JavaScript

Aprender:

- Otimização de código.
- Memória.
- Carregamento eficiente.

---

## 10 - Segurança JavaScript

Aprender:

- XSS.
- Validação de dados.
- Boas práticas de segurança.

---

## 11 - Projetos Avançados

Criar:

- Aplicações completas.
- Integração com APIs.
- Sistemas reais.
