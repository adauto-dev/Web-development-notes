
# JavaScript Médio

## Objetivo

Nesta etapa vamos aprofundar o JavaScript, aprendendo como organizar código, trabalhar melhor com dados e criar aplicações mais interativas.

---

# Conteúdos

## 01 - JavaScript Moderno (ES6+)

Aprender:

- let e const.
- Template literals.
- Destructuring.
- Spread operator.
- Rest operator.

---

## 02 - Funções Avançadas

Aprender:

- Higher-order functions.
- Callback functions.
- Arrow functions avançadas.
- Closures.

---

## 03 - Arrays Avançados

Aprender:

- map().
- filter().
- reduce().
- find().
- sort().

---

## 04 - Objetos Avançados

Aprender:

- Object methods.
- Destructuring de objetos.
- Cópia de objetos.
- Encapsulamento básico.

---

## 05 - Manipulação do DOM

Aprender:

- Criar elementos.
- Remover elementos.
- Alterar classes CSS.
- Trabalhar com formulários.

---

## 06 - Eventos Avançados

Aprender:

- Event bubbling.
- Event delegation.
- Prevenir comportamentos padrão.

---

## 07 - Assíncrono

Aprender:

- Callbacks.
- Promises.
- async/await.
- Tratamento de erros.

---

## 08 - APIs

Aprender:

- Fetch API.
- Requisições HTTP.
- Trabalhar com JSON.
- Consumir APIs externas.

---

## 09 - Módulos JavaScript

Aprender:

- import.
- export.
- Organização de arquivos.

---

## 10 - Ferramentas

Aprender:

- npm.
- Node.js básico.
- Bundlers e ferramentas modernas.

---

## 11 - Programação Orientada a Objetos

Aprender:

- Classes.
- Objetos.
- Herança.
- Métodos.

---

## 12 - Projetos Intermediários

Criar:

- Aplicação de clima.
- Lista de tarefas avançada.
- Consumindo APIs.
- Pequenas aplicações web.
