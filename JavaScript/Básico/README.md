
# JavaScript Básico

## Objetivo

Nesta etapa vamos aprender os fundamentos do JavaScript, a linguagem que adiciona interatividade e lógica às páginas web.

O objetivo é criar uma base forte antes de avançar para JavaScript Médio, Avançado e React.
