# HTML Médio

## Objetivo

Nesta etapa vamos sair do HTML básico e aprender técnicas usadas em projetos reais.

O objetivo é criar páginas mais profissionais, pensando em:

- SEO.
- Acessibilidade.
- Organização.
- Experiência do usuário.
- Boas práticas.

---

# Conteúdos

## 01 - SEO HTML

Aprender:

- Como os buscadores entendem uma página.
- Meta description.
- Títulos corretos.
- Estrutura semântica.
- Boas práticas para aparecer melhor nos resultados.

---

## 02 - Acessibilidade Avançada

Aprender:

- ARIA.
- Leitores de tela.
- Navegação por teclado.
- Formulários acessíveis.

---

## 03 - Formulários Profissionais

Aprender:

- Validação HTML.
- Novos tipos de input.
- Campos obrigatórios.
- Melhor experiência para usuários.

---

## 04 - Estrutura de Sites Reais

Aprender:

- Organização profissional.
- Componentes.
- Padrões usados em empresas.

---

## 05 - HTML e Preparação para CSS

Aprender:

- Classes.
- IDs.
- Organização pensando no design.
- Como preparar HTML para estilização.
