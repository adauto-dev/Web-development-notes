# O que é HTML?

## Definição

HTML significa HyperText Markup Language.

É a linguagem usada para criar a estrutura de uma página web.

## Função

HTML cria:

- Títulos
- Parágrafos
- Imagens
- Links
- Botões
- Formulários

## Como pensar

HTML é como a estrutura de uma casa.

Ele define onde cada coisa existe.
