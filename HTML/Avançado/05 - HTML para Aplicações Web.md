# HTML para Aplicações Web

## O que são aplicações web?

Uma aplicação web é um site que possui funcionalidades e interação com o usuário.

Diferente de um site simples, uma aplicação pode permitir:

- Criar contas.
- Fazer login.
- Salvar informações.
- Agendar serviços.
- Comprar produtos.
- Gerenciar dados.

Exemplos:

- Sistemas de agendamento.
- Redes sociais.
- Lojas online.
- Plataformas SaaS.

---

# Site tradicional x Aplicação Web

## Site tradicional

Normalmente apresenta informações.

Exemplo:

```

```

O usuário lê e navega.

---

## Aplicação Web

O usuário interage com o sistema.

Exemplo:

```

Calendário

```

# Dados do usuário

O HTML coleta informações.

Mas ele não salva sozinho.

Para salvar precisamos de:

Frontend:

```
HTML
CSS
JavaScript
```

Backend:

```
Node.js
```

Banco de dados:

```
PostgreSQL
MongoDB
```

---

# Exemplo de sistema de agendamento

HTML cria:

```html
<form>

<select>

<option>
Corte
</option>

</select>


<input type="date">


<input type="time">


<button>
Agendar
</button>


</form>
```

Depois:

JavaScript controla a interação.

Backend salva os dados.

Banco guarda os agendamentos.
