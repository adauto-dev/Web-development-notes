# HTML Avançado

## Objetivo

Nesta etapa vamos aprofundar conhecimentos de HTML usados em projetos profissionais.

O objetivo não é apenas criar páginas, mas entender como construir uma estrutura preparada para aplicações maiores.

---

# Conteúdos

## 01 - HTML Semântico Avançado

Aprender:

- Estrutura correta de páginas grandes.
- Uso avançado de tags semânticas.
- Organização de conteúdo.
- Boas práticas profissionais.

---

## 02 - SEO Técnico com HTML

Aprender:

- Estrutura para buscadores.
- Dados estruturados.
- Open Graph.
- Melhor organização de páginas.

---

## 03 - Acessibilidade Avançada

Aprender:

- ARIA.
- Navegação por teclado.
- Leitores de tela.
- Boas práticas WCAG.

---

## 04 - Performance HTML

Aprender:

- Carregamento de páginas.
- Otimização de imagens.
- Organização de recursos.
- Boas práticas para velocidade.

---

## 05 - HTML para Aplicações Web

Aprender:

- Estruturas usadas em aplicações.
- Preparação para JavaScript.
- Integração com frameworks.
