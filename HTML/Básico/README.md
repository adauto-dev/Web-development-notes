# HTML Básico

## Objetivo

Nesta etapa aprendemos os fundamentos do HTML, a linguagem responsável pela estrutura das páginas da web.

O objetivo é construir uma base sólida antes de avançar para CSS, JavaScript e frameworks como React.

---

# Conteúdos

## 01 - O que é HTML

Introdução ao HTML e seu papel no desenvolvimento web.

---

## 02 - Estrutura básica

Aprender:

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<body>`

---

## 03 - Tags básicas

Aprender:

- Títulos (`h1` até `h6`)
- Parágrafos
- Quebra de linha
- Comentários

---

## 04 - Links

Aprender:

- `<a>`
- `href`
- Links internos e externos

---

## 05 - Imagens

Aprender:

- `<img>`
- `src`
- `alt`

---

## 06 - Listas

Aprender:

- Listas ordenadas
- Listas não ordenadas
- Itens

---

## 07 - Tabelas

Aprender a criar tabelas com linhas e colunas.

---

## 08 - Formulários Básicos

Aprender:

- `form`
- `input`
- `button`
- `label`

---

## 09 - HTML Semântico

Primeiro contato com:

- `header`
- `main`
- `section`
- `footer`
